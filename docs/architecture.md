# Architecture

Single purpose: get **HP LaserJet 1022** (USB) printing on Apple-Silicon
macOS — and nothing else. Minimum footprint, minimum privilege, fully
auditable, safely removable.

## Print pipeline

```
App → CUPS (system) → pdftops/pstops → application/vnd.cups-raster
      → rastertogutenprint.5.3            (our filter, absolute path in PPD)
      → PCL 5e raster stream  ── [UNVERIFIED on real hardware]
      → /usr/libexec/cups/backend/usb     (Apple's stock USB backend)
      → HP LaserJet 1022
```

If the PCL path fails on hardware, the raster filter is swapped for a
`foo2zjs`-derived ZjStream filter; every other layer stays identical
(see docs/technical-feasibility.md §4).

## Components

| Component | What | Built from |
|---|---|---|
| `rastertogutenprint.5.3` | CUPS raster→PCL5e filter (arm64) | Gutenprint 5.3.5 tarball |
| `cups-genppd.5.3` | PPD generator (arm64) | same |
| Gutenprint XML data | printer/dither/paper definitions | same (`share/gutenprint/5.3`) |
| HP 1022 PPD | one file, absolute `*cupsFilter` path | generated by `cups-genppd` at build time, `LC_ALL=C` |
| Licenses/docs | GPL-2.0 texts, provenance | upstream `COPYING` + `LICENSES/` |

Not shipped: `commandto*` maintenance filters, dyesub/libusb backends,
PPDs for other models, `cups-genppdupdate`, i18n/NLS files.

## Filesystem layout

```
/Library/Printers/HP1022-Gutenprint/          (pkg payload root)
  libexec/rastertogutenprint.5.3
  libexec/cups-genppd.5.3
  share/gutenprint/5.3/...                    (XML, cups model PPD dir)
  share/doc/{COPYING,NOTICE,...}
/Library/Printers/PPDs/Contents/Resources/
  HP1022-Gutenprint-hp-lj_1022.ppd            (one file; payload-owned)
```

- Configure prefix = the payload root, so compiled-in `pkgdatadir` resolves
  without environment variables or symlinks.
- `*cupsFilter:` in the PPD carries the **absolute** filter path — required,
  because `/usr/libexec/cups/filter` is SIP-protected and must not be
  modified. Confirmed working practice (third-party notarized packages do
  the same).
- No files outside these two locations. No `/usr/local` symlinks, no
  `/etc/cups` writes from the pkg.

## Privilege & side-effect model

| Phase | Runs as | Side effects |
|---|---|---|
| fetch / build / test / package | unprivileged user | files under `build/ stage/ dist/` only |
| `installer -pkg …` | admin (sudo) | payload files only; **no preinstall/postinstall scripts** |
| `scripts/install.sh` | user | wraps `installer`, then prints next-steps help only |
| `scripts/add-printer.sh` | admin when creating the queue | `lpadmin` on **explicitly chosen** URI; never default printer; refuses to overwrite an existing queue without `--force` |
| `scripts/uninstall.sh` | admin | manifest-driven removal; `--dry-run` default-safe; queues preserved unless `--remove-queue` |

Deliberately absent (vs. reference projects): no auto-detection of all USB
printers, no queue creation inside the pkg, no `lpadmin -d`, no removal of
other vendors' drivers, no reboot requirement, no kext, no Rosetta, no SIP
changes, no network at install time.

## Reproducibility

- `sources.lock` pins URL + SHA-256 for every downloaded input.
- `scripts/fetch-source.sh` verifies the hash *before* extracting; the
  tarball is kept under `sources/` (gitignored) for re-verification.
- Build outputs land in `stage/`; `dist/` holds the unsigned `.pkg` plus
  `SHA256SUMS` and `payload-manifest.txt` (sorted file list) — the manifest
  is the audit artifact and also feeds `uninstall.sh`.
- No upstream code modifications. If one ever becomes necessary it lands as
  a file under `patches/` applied by `build.sh` and documented here.

## Trust boundary

The pkg is **unsigned and un-notarized** in this iteration (no Developer ID
in CI). `pkgutil --check-signature` will report `Status: unsigned`; install
requires `sudo installer` or Gatekeeper bypass for unsigned pkgs. Ad-hoc
`codesign -s -` on binaries is for Mach-O signature integrity only — it is
*not* notarization and is never presented as such.
